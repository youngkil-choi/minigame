# 미니 아케이드 (minigamegroup)

브라우저에서 바로 즐기는 **간단한 게임 5종 모음**. 설치·로그인·인터넷 연결 없이 HTML 파일 하나만 열면 동작합니다. 외부 라이브러리·서버 의존성이 전혀 없는 순수 HTML · CSS · JavaScript 구현입니다.

## 시작하기

`index.html` 을 브라우저로 열면 게임 선택 홈페이지가 나타납니다. 카드를 클릭해 원하는 게임으로 이동하세요.

## 게임 목록

| 파일 | 게임 | 설명 | 조작 |
|---|---|---|---|
| `index.html` | 🏠 홈 | 게임 선택 갤러리 (허브) | 마우스 |
| `minesweeper.html` | 💣 지뢰찾기 | 숫자를 읽고 지뢰를 추론하는 논리 퍼즐 (난이도 3단계, 첫 클릭 안전) | 마우스 |
| `2048.html` | 🧩 2048 | 같은 숫자 타일을 밀어 합치는 퍼즐 (최고점수 저장) | 방향키 / 스와이프 |
| `snake.html` | 🐍 스네이크 | 먹이를 먹고 자라나는 뱀 (속도 3단계) | 방향키 / 스와이프 |
| `memory.html` | 🃏 메모리 카드 | 같은 그림 짝 맞추기 기억력 게임 (난이도 3종) | 마우스 |
| `tetris.html` | 🧱 테트리스 | 떨어지는 블록으로 줄 완성 (회전 · 하드드롭 · 다음 블록 미리보기) | 방향키 / Space |
| `minesweeper-site.html` | 📄 지뢰찾기 소개 | 지뢰찾기 상세 소개 랜딩 페이지 | — |

## 공통 기능

- 모든 게임은 **단일 HTML 파일**로 독립 실행 가능
- 일관된 다크 테마 디자인 시스템 (모노스페이스 + 앰버 액센트)
- 각 게임 좌상단 `← 게임 모음` 링크로 홈 복귀
- 반응형 레이아웃 · 모바일 터치(스와이프 / D-패드) 지원
- `prefers-reduced-motion` 접근성 대응

## 기술

Vanilla HTML · CSS · JavaScript · 0 dependencies · 100% offline
